Reachy Mini App

Reachy Eleven Agent

An ElevenLabs voice app for Reachy Mini with dashboard setup and robot gestures.

Getting Started

Installation

Install this app from the Reachy Mini app catalog, open its settings page, enter your ElevenLabs agent ID, then start the conversation from the dashboard UI.

uv sync
reachy-mini-daemon --sim  # in another terminal
uv run reachy-eleven-agent

Configuration

ElevenLabs Agent

A public ElevenLabs agent only needs an agent ID. Private agents can also use an optional ElevenLabs API key, stored locally on the robot.
